# 🚀 CoresX API — Public Release

CoresX API is now publicly available.

A simple HTTP API for sending a message and receiving an AI-generated reply. Designed to be lightweight and easy to integrate with any programming language.

## Features
- Simple REST API
- JSON request / response
- Works with any programming language
- Easy integration
